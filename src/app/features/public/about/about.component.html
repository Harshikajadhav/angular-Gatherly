HOW IT WORKS

One platform, different journeys

Gatherly supports each role with clear, purpose-built experiences.

For Citizens

  1. Browse four service categories.
  2. Discover events and organization details.
  3. Register and participate in opportunities.
  4. Report issues related to completed events when applicable.

For Organizations

  1. Register and submit organization information.
  2. Wait for admin verification.
  3. Manage information and events after approval.
  4. View participants associated with events.

For User Organizers

  1. Register as a citizen.
  2. Apply to become a User Organizer.
  3. Wait for admin review and approval.
  4. Create and manage events independently after approval.

For Administrators

  1. Review organizations and organizer applications.
  2. Manage platform users and events.
  3. Confirm events where required.
  4. Manage the four fixed service categories.
